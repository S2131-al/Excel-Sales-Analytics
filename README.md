# Excel-Sales-Analytics# Excel Sales Analytics

## Project Overview

This project analyzes sales and financial data using Microsoft Excel, Power Query, Power Pivot, and DAX.

The objective is to convert raw business data into meaningful insights that help organizations monitor performance and support decision-making.

---

## Sales Report

### Objectives

- Create Customer Performance Reports.
- Compare Market Performance against Sales Targets.

### Business Value

- Monitor sales activities and performance.
- Identify sales trends and KPIs.
- Support customer discount and pricing decisions.
- Discover growth opportunities in potential markets.

---

## Finance Report

### Objectives

- Create Profit and Loss (P&L) Reports by Fiscal Year.
- Create Profit and Loss (P&L) Reports by Months.
- Create Profit and Loss (P&L) Reports by Markets.

### Business Value

- Evaluate financial performance.
- Support budgeting and forecasting.
- Compare current performance with previous periods.
- Improve strategic decision-making.
